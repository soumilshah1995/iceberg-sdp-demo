# Spark Declarative Pipelines examples

Small, local labs for [Spark Declarative Pipelines](https://spark.apache.org/docs/4.1.1/declarative-pipelines-programming-guide.html). Each lab is a pipeline you can run on your laptop with `spark-pipelines`.

| Lab | What it shows |
| --- | --- |
| [lab1](lab1/README.md) | Append customer CSVs to a bronze Iceberg table, then recount age groups in a SQL materialized view |

You need Java 17 and Python 3.10 or newer. Each lab README has the install and run steps.
